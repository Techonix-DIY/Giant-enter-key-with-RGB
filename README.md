DIY Giant Enter Key — Punchable RGB Stress Reliever

Turn your frustration into relaxing RGB mood lights! This repository
contains full construction drawings, dimensions, wiring diagrams, and
code for building a punchable giant Enter key — without any 3D-print
files. All parts can be made using wood, acrylic, foam, cardboard, or
any custom fabrication method.

👉 Watch the full step-by-step build tutorial on YouTube:
https://youtu.be/_sfl-T4GYsY

Overview

This project is a punchable, oversized Enter key designed to safely
absorb impact and trigger smooth RGB lighting effects. It’s perfect for
makers, gamers, desk-toy lovers, or anyone looking for a fun
stress-relief gadget.

Features

-   Full mechanical drawings with dimensions
-   Buildable with basic tools (no 3D printer required)
-   Punch-activated switch mechanism
-   Smooth RGB lighting effects (WS2812 / Neopixel or similar)
-   Simple wiring and low-voltage electronics
-   Ready-to-use Arduino/ESP code
-   Compatible with USB 12V power

Bill of Materials (BOM)

-   Wood / acrylic sheets for the case and key cap
-   Momentary push switch (soft-actuation recommended)
-   Nodemcu ESP8266
-   WS2812/Neopixel LED strip
-   12V power source
-   Wires, solder, glue/hot glue

Diagrams are located in the /electronics/ folder.

Build Steps (Summary)

1.  Cut all pieces based on the measurements in /drawings/.
2.  Assemble the case and keycap structure according to the drawings.
3.  Assemble the PCB.
4.  Upload the code to your ESP8266.
5.  Power it up and test — then enjoy punching the Enter key! 😄
